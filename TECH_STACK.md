# ConflictSense AI - Full Tech Stack (Updated)

## Frontend (Client Application)
- Framework: Flutter
- Language: Dart (SDK >=3.4.0 <4.0.0)
- UI Layer: Material 3 + custom converted design widgets/screens
- State Management: flutter_riverpod
- Navigation: go_router
- Networking: http
- Data/Utilities: collection, intl
- Charts and Maps: fl_chart, google_maps_flutter
- AI SDK (client-side): google_generative_ai
- Vector and Icon Rendering: flutter_svg, cupertino_icons
